# 成本核算：价格记录可修改、初始价设置与趋势图样式 实施计划

> 设计见 `接口文档/成本核算价格记录与趋势图设计.md`。本会话内联执行（executing-plans），每个任务先写失败测试再实现。不提交，除非用户要求。

**Goal:** 价格记录可修改并可重新设置初始价，渠道设置与生效价同步；新前端两张成本图改成数据看板卡片样式。

**Architecture:** 版本表仍是成本唯一依据；model 层新增带行锁的修改与"设置→生效价"同步；controller 共用校验，新增 PUT 修改、PUT 当前价两个接口；渠道保存只在成本字段改动时追加版本。前端把价格记录面板拆成独立组件，图表 spec 抽成纯函数。

**Tech Stack:** Go + Gin + GORM；React 19 + TanStack Query + Base UI + VChart；经典版 Semi UI。

## Global Constraints

- JSON 一律 `common.Marshal/Unmarshal/UnmarshalJsonStr`。
- 行锁用 `lockForUpdate(tx)`，不在调用处写 `clause.Locking`。
- 控制台提示用 `common.ApiErrorT`（英文原文作键），7 个前端语言文件同步；日志行用 `common.LogText`。
- 前端文案走 `t()`；新增键插在相邻键旁，不追加到文件末尾。
- 不改表结构；三库验证用 `SQL_DSN` 跑 controller 集成用例。
